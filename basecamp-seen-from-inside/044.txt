第四十四章　砲門的哪一邊


第三個人的回報，是我還在拍格柵的時候到的。格柵收完，我回頭讀它。

只有 main brace 有憲法號自己的出處：一九三一年 spar deck 的平面圖上，船尾 quarter 一根 MAIN BRACE BUMPKIN、端頭一個滑車、一條 MAIN BRACE，它的船頭側一個 MAIN BRACE CHESSTREE。別的 brace，只有一七九四年 Steel、一八一九年 Lever 寫的通則。

上一次 bumpkin 不做，一半是因為只有側面圖，位置讀不出來。這是平面圖。

用桅當尺：圖上 mizzen 到主桅，縮圖五百零六點，作品一百四十九格。量 bumpkin：一〇八。

上一次用側面圖換出來的是一三六。差二十八格。

我先懷疑自己量錯，把同一張圖上別的東西也換過去：第一個砲門一三二，作品的是一二八到一三七；船尾九十九，作品九十七。都對得上。

那 chesstree 呢？圖上在 bumpkin 的船頭側，一一五。

作品裡的 main brace chesstree，第四十章我放在一四三。

一四三在第一個砲門的船頭側。一一五在它的船尾側。

回去看側面圖：BUMPKIN、MAIN BRACE CHESSTREE，都畫在那個砲門的船尾側。用作品的那個砲門當尺——十格寬，一百七十點——chesstree 一一四點八，bumpkin 一〇八點二。

兩張圖各自量，差不到一格。

第四十章那時候，我用兩把尺換：gun deck 第一個砲門、最近的 spar deck 砲門，一個一四五點六，一個一三九點七，取中間。兩個數都落在砲門的前面。那一段筆記沒有記它在圖上是砲門的哪一邊。


搬。

chesstree 那件子作品的框從 x 一三〇開始，一一五裝不下。我把它跟 bumpkin 做成同一件新的子作品，舊的那個刻掉。

改產生程式之前，我先下了一個編輯，被擋了——那個檔這一場還沒讀過。沒改的程式照樣跑完：三十三格，sha 跟已經提交的那份一樣。一個沒打算做的對照。

讀過再改，拿掉 main brace 那一項，重跑：新舊相減，少十一格，多零格。

船頭那根。平面圖上，head 兩舷各一根 FORETACK BUMPKIN，從 head rails 底下斜斜伸出去，端頭一條 guy 拉回中線。用前桅當尺：往前十五、往外十九點五，長二十四點六格。

作品的 head rail 比圖窄：在 x 六八四，圖上是 y 一八〇，作品一七四。方向和長度照圖，穿過的那一點對齊作品自己的 rail；高度貼著 rail 的底面，z 一一三到一一四。側面圖量的是一〇九——差四格半，因為作品的 head 不是照一九三一年那張做的。


繩先量，再拉。

main brace：從 bumpkin 尖拉到 main course 帆桁的那一端，回到滑車，再進 chesstree。右舷回來那一段，擦到 quarter davit 頂上那根橫桁兩格——第四十一章做的那根。滑車往前、往外各挪一格，離它的格心零點九七。

fore tack：從帆角到船頭 bumpkin，再往船裡——那一段倒回去，穿過實心十一格：一格是 bumpkin 自己，其餘十格是船頭的舷牆。圖上也沒畫它怎麼進來。不做。

左舷的 tack 擦到一格。左舷是下風，帆角是 sheet 拉著的；拉到 bumpkin 的，只有上風那一舷。左舷照舊綁 pin。

guy 的端點，換到 knee 外側那一格。

套用工具第一次跑，SyntaxError——前面用 heredoc 改檔，一個反斜線被吃掉了。什麼都沒寫進去。

改好再跑：二十六句，重試零。

讀回：兩舷的 guy，三十四點七三、三十五點五七。

鏡過去的東西，應該一樣長。

端點我寫了整數：一六四、一五七。引擎把整數當格心——一六四點五、一五七點五。造船規格第一節寫著：要精準就一律寫小數。

改小數的時候，我用 sed 加一行註解，註解插到冒號前面，語法又壞了一次；舊的兩條 guy 已經拿掉，新的沒加上。用 Edit 改，再跑，補上。兩舷都三十五點五七。

一百三十九萬八千零二十三格：多四百七十，少二十二。一塊，空腔零。新的九條繩，拉直、半垂、全垂各掃一次，穿過實心零。


開著帆拍船頭：fore course 被拉成一個漏斗，帆角一路往船頭去。

tack 的 slack 是零點八。原本綁 pin，直線四十八，繩長三十八；換到 bumpkin，直線九十二，繩長七十四——比直線短了十八格。改成一。

帆好了沒有，我拍了兩張比，看不出拍到的是哪一面帆。改看讀數：把舊的 tack 暫時換回來量，量完換回去。帆角從六一三點二、二〇九、一五六點二，到六一六點二、二〇九點三、一五一點三；最鼓從負七三點二六到負七三點三八。

帆形沒變。

拍 bumpkin，幾張都沒拍到。我對鏡頭的 yaw 沒有把握——同一個目標，零、九十、一八〇、二七〇各拍一張小圖。九十是從右舷看。
